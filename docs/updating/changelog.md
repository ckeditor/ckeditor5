# CKEditor&nbsp;5 changelog

This is the CKEditor&nbsp;5 changelog guide. Here you will find information about the most important changes introduced in the release, new features, and bug fixes.

Information about both major and minor breaking changes is available, too, if the release introduces them. You can read more about breaking changes in CKEditor&nbsp;5 in the {@link updating/versioning-policy#breaking-changes Versioning policy} guide.

You can find more information about each release in the blog posts linked at the start of each entry.

This guide covers the three latest releases of CKEditor&nbsp;5. For older releases, see the [Previous releases](#previous-releases) section.

## Previous releases

The changelog above covers the three latest releases only. To learn about older releases:

* Read the [release notes on GitHub](https://github.com/ckeditor/ckeditor5/releases). Every CKEditor&nbsp;5 release has its own entry with the full list of changes.
* Browse the [`CHANGELOG.md` file](https://github.com/ckeditor/ckeditor5/blob/stable/CHANGELOG.md) in the CKEditor&nbsp;5 repository. It collects the changelog entries of all releases in a single file, so you can search across them.
* Check the update guides in the **Update guides** section of the sidebar. They describe breaking changes and migration steps for each major version. For versions older than v42, see the {@link updating/updating-from-older-versions Updating from older versions} guide.
* Read the release announcements on the [CKEditor Ecosystem Blog](https://ckeditor.com/blog/categories/releases/).

## LTS Edition releases

The CKEditor&nbsp;5 LTS Edition is maintained in its own release line, currently `v47.x`. Its releases are not listed in this guide. For their changelog, see the [LTS Edition changelog](https://ckeditor.com/docs/ckeditor5/lts-v47/updating/guides/changelog.html) in the dedicated LTS documentation. To learn more about the LTS Edition, see the {@link getting-started/setup/using-lts-edition CKEditor&nbsp;5 LTS Edition} guide.
