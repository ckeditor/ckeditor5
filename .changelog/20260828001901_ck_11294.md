Editor errors can now be observed with the `onEditorError()` function. It reports errors that escape an editor, together with the editor or context they came from, and returns a function that unregisters the callback. It observes rather than intercepts: nothing is restarted, no editor data is kept or restored, and a reported error still reaches the console exactly as it would with no callback registered. This is the replacement for the Watchdog, which is removed in this major release.
