Several feature packages read the semantic color roles instead of the foundation color tokens. The default look does not change, except that the fullscreen sidebar header uses the UI text color (`--ck-color-text`) when the document outline styles are not loaded. Before, it took the text color of the page. The changed parts:

* Borders and dividers in the special characters, image insert, emoji, and style UI follow `--ck-color-border-control` and `--ck-color-divider`.
* The minimap background, the widget resize handle border, the style previews, and the focus ring gaps in the special characters and emoji grids follow `--ck-color-surface-canvas`.
* The image upload icon follows `--ck-color-text-inverse` and `--ck-color-feedback-success`.
* The find and replace results counter text color can be set with the new `--ck-find-and-replace-form-results-counter-text-color` CSS custom property.

A theme that sets these roles to a custom value also changes these parts.
