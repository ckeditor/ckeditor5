Introduced the `emoticons` text transformation group. It changes text emoticons, such as `:)`, `<3`, or `XD`, into emoji while typing. The group is enabled by default, so editors that use `TextTransformation` with the default configuration will also change these emoticons. To disable the group, add `emoticons` to the `config.typing.transformations.remove` option.

To insert any emoji from the toolbar or by typing `:` and the emoji name, use the [emoji](https://ckeditor.com/docs/ckeditor5/latest/features/emoji.html) feature.
