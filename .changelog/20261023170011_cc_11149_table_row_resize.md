Introduced the table row resize feature. Add the `TableRowResize` plugin to let users set the height of a table row by dragging the bottom edge of its cells, the same way the table column resize feature resizes columns.

Row heights are stored in pixels in the `height` style of `<tr>` elements. Heights in points, for example pasted from Microsoft Word or Google Docs, are converted to pixels. When the table cell properties feature is loaded, its "Height" field sets the height of the row instead of the cell.
