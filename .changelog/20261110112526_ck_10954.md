The find and replace feature should no longer match the text inserted by the replace button. Previously, if the replacement text contained the search phrase (for example, when replacing "Hello" with "HelloHello"), the highlight stayed on or wrapped back to the inserted text instead of moving to the next result, and subsequent replacements kept modifying it endlessly. Starting a new search still finds such matches.
