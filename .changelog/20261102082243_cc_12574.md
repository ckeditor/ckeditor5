The resting shadow of the classic editor toolbar area, the shadow of the selected insert table grid cell under the pointer, and the inner start border width of the split button arrow can be themed on `:root` (or `:host` in a shadow root) with the new `--ck-sticky-panel-content-shadow`, `--ck-insert-table-dropdown-box-hover-shadow`, and `--ck-split-button-arrow-border-inline-start-width` CSS custom properties. Every new property defaults to the current look.
