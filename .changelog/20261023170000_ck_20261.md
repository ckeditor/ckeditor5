Introduced two semantic color roles for accent-colored parts drawn on the canvas: `--ck-color-text-accent` for text and icons, and `--ck-color-border-accent` for borders and thin lines. They are separate from `--ck-color-interactive-primary-surface`, which is a fill. A dark theme can now give these parts a lighter accent that reads well on a dark canvas, while the filled action buttons keep the primary surface color. In the default theme both roles resolve to `--ck-color-base-active`, so nothing changes visually.

The outline button label and border (`--ck-button-outline-color`) and the active tab icon and indicator bar (`--ck-tab-button-active-icon-color`) now read `--ck-color-text-accent`. The border of a toggled-on surface button (`--ck-button-surface-border-color`), the border of the selected style in the style panel, and the hovered table column resizer read `--ck-color-border-accent`. `--ck-color-interactive-selected-text` now follows `--ck-color-text-accent` by default.
