Introduced the `config.ui.overlayContainer` option: the element or shadow root that hosts the editor's floating user interface (balloons, dialogs, and tooltips). Point it at a container of your own when the editor lives inside a shadow root. The editor stylesheets have to be adopted into that container — see the ["Where the floating user interface mounts"](https://ckeditor.com/docs/ckeditor5/latest/getting-started/setup/shadow-dom.html#where-the-floating-user-interface-mounts) section of the shadow DOM guide.

The `config.fullscreen.container` option accepts a shadow root as well now.
