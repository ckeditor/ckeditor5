The results counter in the find and replace form no longer covers the end of the search text, and it uses the search field font size instead of the larger base UI font size. The counter font size can be themed on `:root` (or `:host` in a shadow root) with the new `--ck-find-and-replace-form-results-counter-font-size` CSS custom property.
