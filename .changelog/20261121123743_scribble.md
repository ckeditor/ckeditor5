Handle WebKit dictation input in the Input plugin. WebKit dictation can modify the editing DOM without providing usable text in the `beforeinput` event. Capture the text node before the mutation, detect the subsequent native input event, and extract the inserted text so CKEditor's typing pipeline can process it correctly. Abort pending listeners when they are replaced or the plugin is destroyed. Add tests covering text extraction, listener lifecycle, selection changes, and invalid input events.
