Font sizes written in a different notation than the configured options, for example `2.0em` or `02PX` for the `2em` or `2px` options, are now matched with these options. Previously, such values were not marked as active in the font size dropdown and the menu bar, and they were dropped on upcast when `fontSize.supportAllValues` was disabled.

With `fontSize.supportAllValues` enabled, all numerical font sizes in the loaded content are now normalized, including the ones not present in the configuration. For example, `13.50px` is now output as `13.5px`.
