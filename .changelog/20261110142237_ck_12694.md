Content tables no longer turn into layout tables when the editor data is loaded again with `config.table.tableLayout.preferredExternalTableType` set to `'layout'`. The `content-table` class on the `<figure>` that wraps a table now takes precedence over this setting, so content tables keep their captions, header rows and footer rows.
