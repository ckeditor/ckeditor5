scope:

The `clickOutsideHandler()` utility function no longer accepts the `listenerOptions` option, so the priority and the capture mode of its listener can no longer be configured. Remove the option from the call. The function needs those settings for itself: to detect a click inside a context element that lives in a shadow root, it combines its listener on the document with listeners on the shadow roots of the context elements it is given.
