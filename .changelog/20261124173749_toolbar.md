Add toolbar-specific CSS classes to toolbar containers.

This allows developers to target individual toolbar panels using scoped CSS custom property overrides. The new classes are `ck-toolbar-container_editor`, `ck-toolbar-container_balloon`, `ck-toolbar-container_widget`, `ck-toolbar-container_block`, and `ck-toolbar-container_link`.
