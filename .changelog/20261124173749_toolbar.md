Add toolbar-specific CSS classes to contextual balloon containers.

This allows developers to target individual contextual toolbars, such as balloon, block, widget, and link toolbars, with scoped CSS custom property overrides without affecting other toolbars. Add tests covering class assignment, custom class preservation, and class restoration when switching balloon views.
