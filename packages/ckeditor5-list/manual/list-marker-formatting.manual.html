List marker formatting: headings

When the first block of a bulleted or numbered list item is a heading, the list marker is rendered by that heading, so it has the same font size, family, weight, style and color as the heading. The page defines custom styles for h2 and h3 to verify that the markers reflect the integrator styles too. See also the style feature manual test for block styles.

Testing

  1. Verify the loaded content: markers of list items that start with a heading look like that heading. Other markers look as usual.
  2. Verify that the numbering of the numbered lists is continuous (including the list that starts at 5 and the reversed one).
  3. Change a list item paragraph into a heading and back. The marker should follow.
  4. Make the whole heading text bold, italic or change its font size or color. The marker should follow the inline formatting.
  5. Change the list type to a to-do list. The checkbox should be rendered as usual.
  6. Check the source editing mode. The <li> elements should have the ck-list-marker-from-block class.
  7. Repeat the checks in Chrome, Firefox and Safari.
