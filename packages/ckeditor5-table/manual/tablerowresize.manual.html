Table row resize

Loading and saving

  1. Verify that the row heights from the source are stored in the model as the rowHeight attribute of tableRow (for example with window.editor or the inspector) in the "px", "pt", "Row and cell heights", "Merged rows", "Nested table" and "Resized columns" tables.
  2. Verify that in the "pt" table the heights are converted to pixels (21pt to 28px, 45pt to 60px).
  3. Verify that in the "Unsupported units" table no row has the rowHeight attribute, and that the data has no row heights there.
  4. Switch to the source editing mode and verify that the data contains <tr style="height:…"> for each stored row height.
  5. In the "Row and cell heights" table, verify that the row is as high as the larger of the two heights.

Setting the height in the cell properties

  1. Open the cell properties of any cell: the "Height" field should show the height of the row. Change it: the row height should change at once, "Cancel" should revert it, and "Save" should keep it.
  2. In the "Row and cell heights" table, open the cell properties of the second cell of the first row: the field should show 40px (the row height, even though the 100px height of the other cell makes the row higher), and changing it should remove that cell height.
  3. In the third row of the "Row and cell heights" table (no row height), open the cell properties of the first cell: the field should show its 60px cell height. Changing it should set the row height and remove the cell height.
  4. Type 21pt, 3em or 50%: an error message should be shown and nothing should change.
  5. In the "Merged rows" table, open the cell properties of the merged cell: the field should show the height of the second row, and changing it should resize the second row.

Resizing by dragging

  1. Hover the bottom edge of a cell: a handle should be highlighted across the whole table width and the cursor should change. Drag it down and up: the row height should follow the mouse and be saved after releasing it.
  2. Drag an edge up as far as possible: the row should stop at the height its content requires (no clipped content).
  3. Resize the row without a height in the "Row heights in px" table: it should get a height.
  4. In the "Row and cell heights" table, shrink the first row: it should get lower than the 100px cell height, and the cell height should be removed.
  5. In the "Merged rows" table, drag the bottom edge of the merged cell: the second row should be resized.
  6. In the "Nested table" table, resize a row of the nested table: the outer row should not get a height.
  7. In the "Resized columns" table, resize rows and columns: they should not interfere with each other.
  8. In the "Table wider than the editor" table, resize the last row: its bottom edge should be grabbable from inside the table.
  9. Undo after a drag: the whole drag should be reverted in a single step.
  10. A click on an edge without moving the mouse should not change anything.
  11. Toggle the read-only mode: the handles should disappear.
  12. Click "Enable read-only in 3 seconds" and start dragging an edge: when the read-only mode kicks in, the row should go back to its previous height and nothing should be saved.
  13. Repeat some of the above in the RTL editor.
  14. Pick the open and the closed shadow DOM mode below and repeat the resizing of rows and columns.
