Inheriting formatting when inserting rows and columns

  1. Insert rows above and below, and columns left and right (also with Tab in the last cell). New cells should take the cell styles (borders, background, padding, alignment) from the row or column you acted on.
  2. Type in a new empty cell. The text should continue the formatting (bold, italic, alignment) found at the start of the corresponding cell of the row or column you acted on.
  3. Insert a row below the last heading row: it should become a heading row. Insert a row above the first footer row: it should become a footer row. Insert a column right of the last heading column: it should become a heading column.
  4. Split a styled cell: the new cells should take its styles.
  5. Undo should revert each insertion in a single step.
