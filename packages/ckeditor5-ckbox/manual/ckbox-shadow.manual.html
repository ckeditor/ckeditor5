CKBox in the light DOM, an open Shadow DOM or a closed one

The editor is built in the root picked below. Both CKBox dialogs (the file manager and the image editor) are mounted in the editor body collection and get its root (getRootNode()) as stylesTarget, so CKBox injects its styles there – into the shadow root in the shadow modes, into the document in the light DOM mode.

Adding assets

  1. Click the "Open file manager" icon to open the CKBox dialog.
  2. The dialog should appear inside the selected root and be fully styled.
  3. Chose assets that you want to insert into the editor, then click "Choose".
  4. Selected assets should be inserted into the editor with the following rules:
    • When adding a non-embeddable asset - a text node with URL pointing to that asset should be created.
    • When adding an embeddable asset - it should be visible in the editor.
  5. Inserted assets should have the [data-ckbox-resource-id] attribute in the data.

Editing images

  1. Select an image and click the "Edit image" button in the image toolbar.
  2. The image editor should appear inside the selected root and be fully styled.
  3. Save the edited image – it should replace the original one in the content.

Overlay container

With Overlay layer in its own container on, the body collection (and so both CKBox dialogs) moves to a separate container at the end of <body>. CKBox styles should follow it into that container's root instead of the editor's one.

To check where the styles went, open a dialog and run in the console: editor.ui.view.body.first.element.getRootNode().querySelectorAll( 'style' ). In the shadow modes document.head should not receive any CKBox styles.
