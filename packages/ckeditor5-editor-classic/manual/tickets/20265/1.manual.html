The sticky toolbar covers the selection in a scrollable container #20265

For each editor below:

  1. Place the caret at the start of the first paragraph.
  2. Scroll the dashed container (not the page) down until the caret is out of view above the toolbar.
  3. Type a character.
  4. Scroll the container so that the caret is just under the sticky toolbar and type a character again.

Expected:

  • The container scrolls so that the caret is visible below the sticky toolbar, not behind it.
  • In the nested containers, the caret ends up below the toolbar whichever container the toolbar sticks to.
  • In the editor with a scrollable editable, the editable is not scrolled further than needed: the toolbar does not cover the editable itself, so the editable reserves no space for it.
  • In the small container, there is no room for both the toolbar and the caret. The content does not jump up and down on every key press.
