The sticky toolbar inside a containing block of fixed elements #18328

Each editor is in a wrapper with the CSS property picked below, which makes the wrapper the containing block of the position: fixed sticky toolbar instead of the viewport.

  1. Focus the first editor and scroll its container.
  2. Focus the second editor and scroll the page, also horizontally.
  3. Repeat with each value of the picker, and with "none".
  4. In Safari, repeat while pinch-zoomed in (with the trackpad on desktop).

Expected:

  • The toolbar sticks to the top of the scrolled container (the first editor) or the viewport (the second editor) and stays there while scrolling.
  • It does not jump, and it stays aligned with the editor when the page is scrolled horizontally.
