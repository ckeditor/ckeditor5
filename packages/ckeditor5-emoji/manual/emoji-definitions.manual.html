Emoji definitions passed in the configuration

The page uses the connect-src 'self' Content Security Policy, so the editors cannot download the emoji database from the CKEditor 5 CDN. Both editors get the database in the emoji.definitions option instead.

  • The first editor gets the whole test database. It contains only the "Smileys & Expressions" and "Gestures & People" groups, so other categories in the emoji picker are empty. Type :wav and check that the "waving hand" emoji is suggested.
  • The second editor gets only the "Smileys & Expressions" group. Only this category should have emoji. Typing :wav should not suggest the "waving hand" emoji.
  • Clicking an empty category in the emoji picker should show the "There are no emojis in this category." message without errors.
  • The console should not show any request to the CDN, any CSP violation, or any emoji-repository-* warning.
