Image insert via URL

  1. Click on the arrow button in insertImage plugin to reveal the image insert panel.
  2. Click the Insert via URL button to open the dialog.
  3. Paste the URL to the input (eg: https://ckeditor.com/docs/ckeditor5/latest/assets/img/malta.jpg).
  4. Click Insert button.

Image replace via URL

  1. Click on the image in the editor.
  2. Click on the arrow button in insertImage plugin to reveal the image insert panel.
  3. Click the Update image URL button to open the dialog.
  4. Edit the value of the input.
  5. Click Save button.

Image insert via integrations

  1. In the Editor 2 click on the arrow button in insertImage plugin to reveal the image insert panel.
  2. Click on the CKFinder button.
  3. Choose image and confirm.

Keyboard navigation in the image insert dropdown

  1. With the default integrations, focus the toolbar (Alt+F10), move to the insertImage dropdown and open it with Arrow down.
  2. Arrow down / Arrow up should move the focus between the buttons in the panel (cycling). Arrow left should close the panel. Tab should leave the panel, just like in other list-like dropdowns (e.g. Heading).
  3. Check the Custom integration with a text field checkbox and open the panel again.
  4. Now Tab / Shift+Tab should move the focus between all items (as before). The arrow keys in the Custom image URL field should only move the caret and must neither move the focus nor close the panel.

Image insert via pasting URL into editor

  1. Copy image URL to clipboard (eg: https://ckeditor.com/docs/ckeditor5/latest/assets/img/malta.jpg).
  2. Paste the URL to the editor.
